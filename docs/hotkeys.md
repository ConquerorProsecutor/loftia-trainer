# Default Hotkeys

| Key  | Action                         |
|------|--------------------------------|
| F1   | Toggle god-mode                |
| F2   | Refill health to 100           |
| F3   | Unlock all inventory slots     |
| F4   | Teleport to `market` waypoint  |
| F5   | Teleport to `farm` waypoint    |

Rebind by editing `loftia_trainer/handlers/hotkey_handler.py::DEFAULT_BINDS`, or set `hotkeys_enabled = false` in `config/trainer.toml` to disable the keyboard hook entirely.
